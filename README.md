# Heart Disease Prediction using Machine Learning

## 📌 Project Description

The **Heart Disease Prediction System** is a Machine Learning project that predicts whether a person is likely to have heart disease based on various health-related features.

The project uses **Python and Scikit-learn** to preprocess the data, train a Machine Learning model, and evaluate its performance.

## 🚀 Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Feature selection
* Machine Learning model training
* Heart disease prediction
* Model performance evaluation
* Accuracy and ROC-AUC evaluation

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Scikit-learn**
* **Jupyter Notebook**

## 🔄 Project Workflow

```text
Heart Disease Dataset
        ↓
Data Cleaning
        ↓
Exploratory Data Analysis
        ↓
Feature Selection
        ↓
Train-Test Split
        ↓
Machine Learning Model
        ↓
Model Evaluation
        ↓
Heart Disease Prediction
```

## 🎯 Objective

The main objective of this project is to develop a Machine Learning model that can analyze patient health information and predict the possibility of heart disease.

## 📊 Model Evaluation

The model is evaluated using metrics such as:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC
